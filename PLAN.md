## Working rules and excluded work

Use red/green TDD for code changes. Preserve launch-origin semantics: inherited markers do not prove which session currently uses a shared daemon. Never guess from a shared directory. Keep unresolved agent-associated heavy processes visible; the implemented wider-process visibility switch is tracked in CLI-02. Update this plan with a concrete next action or blocker, not a claim of completion without evidence.

Desktop attribution, a menu bar/app UI, packaging, notifications, termination controls, broad provider support, and production hardening are outside this PoC plan. The [tier working model](docs/research/agent-working-model.md) remains a proposal; this task list does not authorize delegation or automatic implementation of excluded work.

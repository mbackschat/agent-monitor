### Existing scope decisions

The shipped scope includes text/TUI/JSONL reports, session grouping in text and TUI, built-in Codex/Claude attribution, confirmed single-process termination, verified session messaging and terminal focus through both TUI and CLI actions. Preserve the [architecture boundaries](docs/architecture.md) when extending it.

Accepted deferral (2026-10-16): [Codex registry integration](docs/decisions/codex-session-registry.md) waits for a verifiable native process relation; the current methods do not resolve marker-less children of shared runtimes.

Pending ideas, not yet approved for implementation:

- A compact provider column with sorting and a command-line-only provider filter. Provider recognition must come from attribution adapters; this is separate from the completed extraction.
- Author credit in `--help`.

Production app packaging, desktop/remote/container attribution, broader platform/provider support, notifications, background monitoring services, additional terminal adapters/tmux resolution, optional session metrics and external plugins need separate scope decisions. The native menu bar app is maintained as a source-built feature with shared sampling, grouping and verified actions; its [architecture](docs/architecture.md#native-menu-bar-app) defines 15-second closed-panel sampling for the live icon and no closed-panel sampling for the optional static icon. Its deferred product decisions are [recorded](docs/decisions/menubar-product-scope.md). The [working-model proposal](docs/proposals/agent-working-model.md) does not authorize delegation. Dated source findings belong in the [research index](docs/research/README.md).

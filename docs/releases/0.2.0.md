# Agent Monitor 0.2.0

Act on the session behind the load.

This release adds actions on heavy processes and their agent sessions, from the terminal UI and the command line.

## Included

- **Terminate** one process with SIGTERM after reviewing it (`k`, or `agent-monitor kill --pid`).
- **Message** the process's session (`s`, or `agent-monitor message --pid --text`): the verified Codex root or selected agent through the local app server, or the Claude Code session through its local inbox. The selected PID and process name are prepended, and the exact message is reviewed before sending.
- **Focus** the terminal hosting the session (`f`, or `agent-monitor focus --pid`): Terminal.app selects the session's tab; other terminal apps are brought to the front. Works on a selected process or a session group.
- Command-line actions ask for confirmation in a terminal and require `--yes` in scripts. Exit status 2 marks a message that may have been accepted.
- TUI: change the update interval live with `<` and `>` (0.5–60 seconds), and freeze the view with Space while sampling continues.
- Colors for text reports and action output on a terminal, and `--no-color` for text, TUI and actions. JSONL is never colored.
- Attribution: background jobs whose shell exited are linked back to their live Claude Code runtime, and workloads of one agent started inside the other (Codex → Claude Code or the reverse) are attributed to the inner agent instead of being marked ambiguous.
- Smaller download: the packaged executable is stripped.

## Install

Download `agent-monitor-0.2.0-macos-arm64.tar.gz` and its `.sha256` checksum, or upgrade with `brew upgrade mbackschat/tap/agent-monitor`. See the [installation guide](https://github.com/mbackschat/agent-monitor/blob/v0.2.0/docs/installation.md).

Requires **Apple Silicon and macOS 27**. Xcode is not needed to run the download. Source builds require Xcode 27 with Swift 6.4.

The binary is ad-hoc signed, not Developer ID signed or notarized. macOS may block downloaded copies; source-build instructions are provided as an alternative.

## Scope and limitations

Accepted actions are not confirmed outcomes: SIGTERM acceptance does not mean the process exited, and a handed-over message may be held, refused, or not acted on. Messaging needs Codex CLI with its default local app server, or Claude Code 2.1.224 or later; Claude Code does not document its inbox message format, which may change between releases. Focusing a terminal asks once for macOS Automation permission for the terminal running Agent Monitor; only Terminal.app tabs are selected, and sessions under tmux, screen or ssh cannot be focused. Attribution still describes launch origin, not which session currently drives a shared daemon.

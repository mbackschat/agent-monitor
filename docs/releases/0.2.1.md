# Agent Monitor 0.2.1

A maintenance release: lighter live waiting and clearer action messages.

## Changed

- **TUI interval changes apply at once without polling.** The live view no longer checks for a changed interval four times a second; changing it with `<` or `>` wakes the waiting sample directly, so an unchanged interval costs one wake-up per sample.
- **Focus failures read correctly outside the TUI.** When macOS has not yet allowed Terminal automation, or Terminal does not answer in time, `agent-monitor focus --pid` and the TUI both say "try again" instead of naming the TUI's `f` key.
- **Stricter provider replies.** Codex and Claude Code replies used to verify a recipient are now decoded against fixed shapes; a reply with a changed field type is refused rather than read loosely, and no message is sent.
- The README lists messaging, terminal focus, command-line actions, interval control and freezing as features.
- Internal cleanup: shared wording, number formatting, column padding and message-length limit across the text report, TUI and command line, and smaller attribution and rendering functions. Output is unchanged.

## Install

Download `agent-monitor-0.2.1-macos-arm64.tar.gz` and its `.sha256` checksum, or upgrade with `brew upgrade mbackschat/tap/agent-monitor`. See the [installation guide](https://github.com/mbackschat/agent-monitor/blob/v0.2.1/docs/installation.md).

Requires **Apple Silicon and macOS 27**. Xcode is not needed to run the download. Source builds require Xcode 27 with Swift 6.4.

The binary is ad-hoc signed, not Developer ID signed or notarized. macOS may block downloaded copies; source-build instructions are provided as an alternative.

## Scope and limitations

Unchanged from [0.2.0](0.2.0.md#scope-and-limitations): accepted actions are not confirmed outcomes, Claude Code's inbox message format is undocumented, only Terminal.app tabs are selected when focusing, and attribution describes launch origin.

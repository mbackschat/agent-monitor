# Agent Monitor 0.1.0

Released 2026-10-14.

Find the session behind the load.

The first release traces heavy CPU and memory consumers to Codex CLI and Claude Code launch sessions on macOS.

## Included

- Live terminal report with sorting, process details, and a layout that adapts to terminal width.
- Session grouping with totals for displayed heavy processes.
- Live CPU and memory filters, adjustable by 10 percentage points and 1 GB.
- Plain-text reports and streaming JSONL with a bundled JSON Schema.
- Explicit unknown and ambiguous attribution, with terminal/project context when available.
- `agent-monitor --version` for identifying the installed release.

## Install

Download `agent-monitor-0.1.0-macos-arm64.tar.gz` and its `.sha256` checksum. The archive includes the executable, required schema resource bundle, installation instructions, and licenses. See the [installation guide](https://github.com/mbackschat/agent-monitor/blob/v0.1.0/docs/installation.md).

Requires **Apple Silicon and macOS 27**. Xcode is not needed to run the download. Source builds require Xcode 27 with Swift 6.4.

The binary is ad-hoc signed, not Developer ID signed or notarized. macOS may block downloaded copies; source-build instructions are provided as an alternative.

## Scope and limitations

Attribution describes launch origin. It does not prove which session is currently driving a shared daemon. Session totals include displayed heavy processes only. Claude Code's native installation has real-workload validation; npm-based Claude installations and real terminal Codex workloads remain unvalidated. No desktop conversation attribution, process termination, messaging, or third-party plugins are included.

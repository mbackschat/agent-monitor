# Contributor overview alternatives

Status: **rejected**, 2026-10-28. This status applies to replacing the accepted ledger with the alternative primary layouts below. The user selected a ranked ledger with activity lanes and full-width workload context; its implemented contract belongs in [architecture](../architecture.md#constrained-overview-presentation), with the [studies and evidence](../research/native-menu-design.md#ledger-studies-and-temporal-publication--2026-10-28) retained separately.

## Alternatives considered

| Study or option | Useful property | Disposition |
| --- | --- | --- |
| A: ranked ledger | Efficient comparison of several sessions; aligned resources and stable hierarchy | Accepted as the main structure. |
| B: workload board | Recognisable jobs and prominent workload summaries | Adopt readable values and workload context, but not independent cards: expansion and five or more sessions need a shared comparison structure. |
| C: responsibility matrix | Reveals sessions sharing directories | Not selected: directories become the primary navigation unit and a wider analytical surface is needed. |
| D: activity lanes | Explains bursts and quiet periods beside ownership | Adopt within the ledger; do not make a timeline the sole organising principle. |
| Taller row versus wider window | Either can relieve the identity/chart collision | Use a separate full-width context band and a 620-point Mac panel. Width alone does not prevent text competing with a chart. Keep the chosen panel height and scroll. |
| Repeated microbars and recent-CPU subtitles on every metric cell | Adds local quantitative cues | Removed from the overview in favour of one comparable history lane and current values. Recent CPU remains explicit for departed work and in details. |
| Per-row information popovers | Keep details close to a row | Replaced by one bottom inspector, retaining the comparison list and full wrapping paths. |
